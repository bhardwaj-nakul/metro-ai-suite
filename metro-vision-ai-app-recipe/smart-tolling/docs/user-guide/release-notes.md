# Release Notes: Smart Tolling

## Version 2026.3.0

**Release Date**: December 7, 2026

This is the initial release of the Smart Tolling sample application.

**Features**:

- Multi-camera fusion of front, rear, and side views across six parallel video pipelines.
- Vehicle detection and classification.
- License plate detection and recognition from front and rear views.
- Vehicle color classification.
- Axle counting with lift-axle detection for accurate tariffing.
- Evidence images attached to every toll transaction for auditing.
- Real-time and historical dashboards for traffic volume, flow efficiency, and vehicle events.
- Modular microservice architecture based on DL Streamer, Scenescape, Node-RED, InfluxDB, and Grafana.
- Optimized video pipelines with hybrid GPU, NPU, and CPU workload distribution on Intel edge devices.
